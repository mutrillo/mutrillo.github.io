Uma curiosidade por dia, direto no feed

CurioBot

Carrosséis de curiosidades gerados e publicados no Instagram através da API oficial da Meta, com o dono da conta no controle o tempo todo.

Como funciona

  1. A conta do Instagram é conectada de forma oficial, usando a Graph API da Meta — sem senhas armazenadas fora da própria Meta.

  2. Um conjunto de curiosidades é selecionado e transformado em slides de carrossel, com texto e imagem gerados para o formato do Instagram.

  3. Os slides passam por uma fila de publicação com horários definidos, sempre dentro dos limites de uso da própria API da Meta.

  4. Cada carrossel é publicado na conta autorizada, mantendo o histórico do que já foi postado para nunca repetir um conteúdo.

O CurioBot publica apenas na conta que o autorizou a fazer isso, dentro das regras da plataforma da Meta — nada de conteúdo enviado para contas de terceiros.

Perguntas frequentes

O que é o CurioBot?
É uma automação que gera e publica carrosséis de curiosidades no Instagram, usando a API oficial da Meta para acessar a conta autorizada e realizar as publicações.
É seguro conectar minha conta do Instagram?
Sim. A conexão usa apenas a autenticação oficial da Meta (OAuth). Nenhuma senha é armazenada fora da própria Meta, e o acesso pode ser revogado a qualquer momento pelas configurações da conta.
O conteúdo é publicado sem revisão?
O conteúdo é gerado e agendado automaticamente, mas segue um roteiro fixo de curiosidades e formatos definidos previamente pelo responsável pela conta — não há geração livre nem publicação fora desse escopo.
Isso é usado para postar em massa ou spam?
Não. As publicações seguem uma frequência fixa e moderada, dentro dos limites de uso da API da Meta, e respeitam as diretrizes de conteúdo do Instagram.
Como revogo o acesso à minha conta do Instagram?
Pelo Instagram ou Facebook: em Configurações → Segurança → Apps e sites conectados, localize o app e selecione remover acesso. O efeito é imediato.
Quais dados da conta são acessados?
Apenas o necessário para publicar conteúdo em nome da conta autorizada — permissões de publicação da Graph API. Nenhum dado é vendido ou compartilhado com terceiros.
Preciso de uma conta comercial do Instagram?
Sim, a publicação automática via Graph API exige uma conta comercial ou de criador de conteúdo vinculada a uma Página do Facebook, conforme exigido pela própria Meta.
